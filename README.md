# Houston

Один из первых проектов, написанных при изучении frontend разработки в июне 2023 года.

Проект представляет собой реализацию макета, предложенного в ходе прохождени курса ["Веб-разработка для начинающих: HTML и CSS"](https://stepik.org/38218) на платформе [stepik.org](https://stepik.org/learn). 

Проект был направлен на закрепление следующих тем: 
- семантическая корректность, выбор подходящих тегов;
- создание якорей на заголовки содержания.
